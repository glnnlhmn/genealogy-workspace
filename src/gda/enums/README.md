# GDA Categorical Enumerations (`gda.enums`)

## Operational Role & Purpose
Canonical enumeration definitions establishing controlled classifications, status codes, and type markers across the digital archive.

## Architectural Governance
- **Canonical Architecture**: Complete and authoritative categorical definitions across the codebase.
- **Enumeration Domains**:
  - `archival.py`: Document preservation statuses, archival media classifications, and repository conditions.
  - `core.py`: Foundational system state flags, record statuses, and generic execution categories.
  - `fiscal.py`: Historical taxation types, census record enumerations, and economic status markers.
  - `site.py`: Facility classifications, repository types, and geographic location designations.
  - `sources.py`: Evidentiary source categories, confidence ratings, and citation classifications.
  - `vital.py`: Vital event classifications (birth, marriage, divorce, death, probate, burial).

## Development Status
Completed and canonical. Provides stable classification types for models, entities, and managers.
